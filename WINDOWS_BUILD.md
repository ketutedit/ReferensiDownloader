# Referensi Downloader — Windows CI

GitHub Actions builds the Windows x64 version from the bundled v2.3 source.

Artifacts produced:
- ReferensiDownloader-Windows-x64-Portable.zip
- ReferensiDownloader-Windows-x64-Setup.exe

Workflow: `.github/workflows/build-windows.yml`

The source bundle is stored at `source/ReferensiDownloader-v2.3-GitHub-WindowsBuilder.zip`.
